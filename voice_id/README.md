# voice_id — идентификация говорящего по голосу

Нимфея помнит, **кто с ней говорит** (требование 9): эмбеддинг каждой фразы
сравнивается с голосовыми профилями из `memory.people[].voice_embeddings`
(до 5 эталонов на человека — голос «плавает» между фразами, один вектор
этого не покрывает; урок живого прогона 11.09: каждая фраза заводила нового
«Друга N» со схожестью 0.17–0.65).

- Движок: speechbrain ECAPA-TDNN, CPU, без VRAM. Установка:
  `pip install speechbrain` (модель ~80 МБ скачается в `cache/ecapa` при
  первом использовании). Без пакета — деградация: `mic` = владелец
  (`NIMA_VOICE_ID_USER`), `loop` = «Собеседник».
- **Канал mic = владелец (v14.8.17)**: микрофон — это микрофон владельца,
  поэтому с него чужие профили НЕ присваиваются и новые «Друга N» НЕ
  заводятся (урок 13.09: 47 «Другов» из одного голоса владельца).
  Микрофонные фразы только уточняют профиль владельца (`VOICE_ID_USER`,
  по умолчанию «Кизилл»). Все прочие люди — через loop-канал (созвон) или
  представляются словами.
- Гистерезис опознания (v14.8.7):
  - косинус ≥ 0.72 (`NIMA_VOICE_ID_THRESHOLD`) — опознан, эталон добавляется
    в профиль (профиль «дозревает», разные интонации остаются различимыми);
  - ≥ 0.50 (`NIMA_VOICE_ID_SOFT`) — «похоже на лучший профиль»: фраза
    прикрепляется к нему, новый профиль НЕ заводится;
  - ниже — новый «Друг N» только если фраза ≥ 1.5 с
    (`NIMA_VOICE_ID_MIN_NEW_SEC`): короткие обрывки/шум профили не создают.
- **Запись голоса в профиль**: debug menu → ИНСТРУМЕНТЫ → ЗАПИСЬ ГОЛОСА
  (6 секунд с микрофона; команда `enroll_voice` уходит в запущенную Нимфею
  через `cache/manual_commands.json`, результат — `cache/enroll_result.json`).
  Программно: `voice.enroll(имя, audio)`.
- Незнакомый голос (заглушка «Друг N»/«Собеседник») → пайплайн добавляет в
  промпт указание спросить имя (не чаще раза в 15 мин на голос,
  `NIMA_ASK_NAME_COOLDOWN`). Представление «меня зовут X» закрепляет имя за
  голосом (`memory.rename_person`), эталоны переносятся.
- Настоящее имя голосу даёт пользователь: `memory.rename_person("Друг 1", "Тоник")`
  (экран ИСТОРИЯ ДИАЛОГОВ / ручной ввод).

```python
from voice_id import VoiceID
voice = VoiceID(memory)
speaker = voice.identify(audio_float32_16k, channel)  # → имя
voice.enroll("Кизилл", audio)                         # ручной энроллмент
```

Юнит-тест логики (без ECAPA): `tests/test_voice_id_hysteresis.py`.
Выключение: `NIMA_VOICE_ID=0`.
