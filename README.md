# Neyronya — Нимфея (v14)

Локальная ИИ-стримерша **Нимфея** (близкие зовут **Нима**): голосовой компаньон
с дообученной LLM, клонированным голосом, распознаванием речи и прозрачным
3D-окном (VRM + VRMA-анимации).

## Запуск

1. **`debug menu.bat`** → секция ЗАПУСК → **[ ▶ ЗАПУСТИТЬ НИМФЕЮ ]**.
   Кнопки ЗАПУСК / РЕСТАРТ / ВЫКЛЮЧИТЬ подключены к оркестратору `start.py`.
2. Первый запуск: XTTS скачает модель (~1.8 ГБ), faster-whisper — STT-модель,
   voice_id — ECAPA (~80 МБ в `cache/ecapa`). Это разовое, дальше старт быстрый.
3. Ручной ввод текста — debug menu → ИНСТРУМЕНТЫ → **РУЧНОЙ ВВОД**
   (`реплика` — спросить; `Нима: реплика` — озвучить сразу).

Требования: Python 3.12 (venv `myenv/` создаётся рядом), Ollama с моделью
`nimfea`, Node.js — только для пересборки аватара.

## Архитектура (v14)

```
start.py         оркестратор (composition root) — только связывание модулей
core/            конфиг, лог, шина событий, трасса пайплайна
memory/          память → memory.json (корень) + голосовые профили + векторный recall
prompts/         построитель промптов + персона Нимфеи
llm/             LLM: Ollama + дообученная nimfea (gemma3+LoRA v7, Q4_K_M + mmproj —
                 models/nimfea_full/), стрим + зрение тем же Ollama
stt/             распознавание: faster-whisper, CPU — микрофон + LOOPBACK (созвон)
ears/            гейт адресации: слышит всегда, отвечает только по имени
voice_id/        кто говорит: идентификация по голосу (speechbrain ECAPA, CPU)
tts/             озвучка: Silero baya (CPU, основной) + XTTS/Chatterbox как
                 опции бэкенда; референсы «Референс 1/2.wav» — для XTTS-клона
web/             интернет-поиск ([ПОИСК] + поиск до ответа по триггерам, v14.8.47)
pipeline/        диалоговый конвейер: стриминг LLM→предложения→TTS, нити, донаты
initiative/      живая инициатива (сама заводит разговоры, когда тихо)
avatar/          прозрачное Electron-окно с VRM + VRMA-анимации (мост из Python)
twitch/          чат стримерши + приёмник донатов (HTTP :8791 / файловый ящик)
training/        сборщик лора-датасета из памяти + README по LoRA
debug_menu/      меню разработки (SAVE/RESTORE, КОНСОЛЬ, песочница, тесты)
docs/            архитектура и история версий
```

Каждый модуль изолирован и имеет свой `README.md` с инструкциями.
Зависимости: `pipeline → все модули → core`, подробнее
`docs/ARCHITECTURE.md`. Полный каркас v14 и статус по 21 требованию —
`docs/SKELETON.md`.

## Управление окном аватара

- верхняя **центральная** точка — перетаскивание окна; **двойной щелчок** —
  блокировка/разблокировка изменений окна;
- верхняя **правая** точка — изменение размера (симметрично, от центра);
- перетаскивание самой Нимфы мышью — двигает её внутри окна;
- анимации: `vita_avatar_app/animations/*.vrma` — файл в папке = действие
  в песочнице debug menu (`vrma_<имя>`).
