# prompts — построитель промптов

Собирает system-промпт Нимфеи: персона + контекст памяти. Последний собранный
промпт сохраняется в `cache/last_prompt.txt` — его показывает debug menu
(экран «ПРОМПТ»).

| Файл | Роль |
|------|------|
| `persona.py` | **Персона Нимфеи — единый источник правды о характере.** Менять характер только здесь |
| `prompt_builder.py` | `build_system()` (system-текст + контекст памяти) и `get_history()` (история диалога из memory/) |

## Как редактировать характер

Правишь текст в `persona.py` — ничего больше. Правила от v11 сохраняются:
не стерилизовать Нимфею (сарказм, чёрный юмор, умеренная вульгарность и мат —
часть образа), ограничивать только бессмысленную токсичность.

## Изоляция

Модуль знает про `memory/` (берёт контекст) и ничего больше. LLM получает
system+history через пайплайн. Не добавляй сюда логику ответов — это работа
`pipeline/`.
