# pipeline — диалоговый конвейер

Связывает все модули: вход → LLM → TTS → аватар → память.

```
STT (микрофон) ─┐
Ручной ввод ────┼─→ DialoguePipeline ─→ prompts → llm → tts ─→ аватар (липсинк, mood)
Twitch-чат ─────┘        │
                         └─→ memory (история dialog)
```

| Файл | Роль |
|------|------|
| `pipeline.py` | `DialoguePipeline.handle_user_text(text, source)` — полный цикл ответа |
| `manual_control.py` | Файловая очередь ручного ввода из debug menu (`cache/manual_commands.json`) |

## Правила пайплайна

1. Новая реплика пользователя **прерывает** озвучку (перебивание).
2. Пока Нимфея говорит — **STT на паузе** (самоуслышивание).
3. LLM и озвучка — в worker-потоке: главный цикл start.py не блокируется,
   реплики обрабатываются по очереди.
4. Каждый ответ пишется в память и в лог тегом
   `[SpeakText] source=nima:llm text=…` (КОНСОЛЬ подсвечивает его).
5. Настроение ответа детектируется по ключевым словам → `mood` аватара
   (без второго запроса к LLM).

## Ручной ввод (debug menu → РУЧНОЙ ВВОД)

- `реплика` — как реплика пользователя (Нимфея отвечает);
- `Нима: реплика` / `Нимфея: реплика` — озвучить сразу, минуя LLM;
- `!regen реплика` — повтор последнего ввода.

## Изоляция

Модуль импортирует остальные и связывает их колбэками. Здесь единственное
место, где допустимо знать всех. Добавление нового источника ввода (донаты,
чат) — новый вызов `handle_user_text(text, source="...")`.
