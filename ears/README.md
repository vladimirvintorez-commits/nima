# ears — гейт адресации

Нимфея **слышит всегда**, а **отвечает только когда к ней обращаются по имени**
(«Нимфея», «Нима», «Ним»… — список форм в `core/config.py` → `NIMA_EARS_NAMES`).

- Regex по формам имени + fuzzy-оболочки (STT коверкает: «мифея», «нимффа»).
- Сомнительные случаи решает резервный микро-классификатор LLM (`num_predict=3`).
- Неадресованные реплики пишутся в память как «подслушанные»
  (`NIMA_EARS_OVERHEAR=1`) и видны движку инициативы.
- Канал loopback (собеседник из созвона) проходит через тот же гейт.

Использование:
```python
from ears.ears_module import is_addressed, strip_name

if is_addressed(text, llm):
    text = strip_name(text)   # суть без обращения
```

Отключить гейт целиком: `NIMA_EARS_ENABLED=0`.
