# core — общая инфраструктура

Общий фундамент всех модулей Нимфеи. **Никогда не импортирует другие модули
проекта** — зависимости направлены только вниз (`llm/`, `tts/`, … → `core/`).

| Файл | Роль |
|------|------|
| `config.py` | Все пути и настройки. Переопределение — переменные окружения `NIMA_*` |
| `logging_setup.py` | Единый лог `logs/technical_context.log` + тег реплик `[SpeakText] source=nima:*` |
| `events.py` | Шина событий: модули общаются подписками, не прямыми импортами |

## Правила работы с модулем

- Новые пути/настройки — только в `config.py`, с дефолтом и env-переопределением.
- Менять формат лога нельзя: `debug_menu/runtime_console.py` ищет `[ERROR]`,
  `[WARNING]` и `[SpeakText] source=nima...` в строках.
- Файл памяти задан в `config.MEMORY_JSON` — владелец файла только `memory/`.

## Инструкция по проекту

Запуск: `debug menu.bat` → «ЗАПУСТИТЬ НИМФЕЮ» (или напрямую `myenv\Scripts\python.exe start.py`).
Остановка: кнопка «ВЫКЛЮЧИТЬ ПРОЕКТ» в том же меню. Архитектура — `docs/ARCHITECTURE.md`.
