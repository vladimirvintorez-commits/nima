# tts — модуль озвучки Нимфеи (клонирование голоса)

Coqui XTTS v2, голос клонируется по двум референсам из корня проекта:
`Референс 1.wav` и `Референс 2.wav` (по 10 секунд, 44.1 кГц — этого хватает
для устойчивого клона). Устройство: авто → `cuda` (~2 ГБ VRAM, рядом с
LLM ~2 ГБ влезает в 6 ГБ), при недоступности — CPU (медленнее).

| Файл | Роль |
|------|------|
| `tts_module.py` | `TTSModule`: `speak(text)` (блокирующий, вызывать из worker-потока), `stop()`, `warmup_async()` |

## Как это работает

1. Текст чистится: эмодзи/разметка вырезаются, длина режется
   (`NIMA_TTS_MAX_CHARS`, 400).
2. Синтез в temp-wav: `speaker_wav=[референсы]`, `language="ru"`.
3. Воспроизведение чанками по 100 мс (sounddevice); на каждый чанк считается
   RMS → колбэк `on_mouth(0..1)` — это **липсинк** аватара.
4. `stop()` прерывает воспроизведение (перебивание).

## Модель при первом запуске

XTTS v2 скачивается с HuggingFace (~1.8 ГБ) в `~\AppData\Local\tts\` — один
раз. Согласие с лицензией подставляется автоматически (`COQUI_TOS_AGREED=1`).

## Изоляция

Модуль не знает про LLM/память/аватар: колбэки `on_mouth/on_start/on_end`
подключает пайплайн. Прогрев фоновый — старт проекта не блокируется.
