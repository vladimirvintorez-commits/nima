# twitch — модуль чата стримерши

Нимфея-стримерша видит чат: IRC по TLS (только чтение), сообщения уходят в
пайплайн как реплики от лица чата. Модуль **опционален**: без конфига проект
живёт как голосовой компаньон.

## Включение

Переменные окружения перед запуском start.py:

```
set NIMA_TWITCH_CHANNEL=имя_канала
set NIMA_TWITCH_TOKEN=oauth:xxxx      # https://twitchapps.com/tmi/ (chat:read)
set NIMA_TWITCH_NICK=nimfea_bot
```

Сообщения приходят в пайплайн как
`Сообщение из чата от {nick}: {text}` — Нимфея сама решает, отвечать ли.

## Файлы

| Файл | Роль |
|------|------|
| `twitch_module.py` | `TwitchModule(on_message)`: `start()`/`stop()`, авто-PING/PONG |

## Изоляция

Модуль ничего не знает про LLM/голос: только колбэк `on_message(nick, text)`.
Расширения на будущее: донаты (EventSub), ответы адресно, банворды чата.
