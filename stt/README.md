# stt — модуль распознавания речи (CPU)

faster-whisper (CTranslate2, int8) на CPU — качество без расхода VRAM.
Микрофон пишется постоянно (sounddevice, 16 кГц моно), фразы нарезаются по
энергии: по умолчанию 0.5 с тишины = конец фразы. Повторный VAD Whisper
выключен, чтобы не обрезать уже выделенные короткие русские фразы; его можно
вернуть через `NIMA_STT_WHISPER_VAD=1`.

| Файл | Роль |
|------|------|
| `stt_module.py` | `STTModule(on_utterance)`: `start()`, `stop()`, `pause(True/False)` |

## Как это работает

1. Поток микрофона → блоки по 100 мс в очередь.
2. Отдельный поток: RMS каждого блока против адаптивного порога шума →
   сегменты речи (минимум `NIMA_STT_MIN_SPEECH` сек).
3. Готовый сегмент → `transcribe(language="ru", beam_size=5)`; внутренний VAD
   включается только флагом, prompts разделены для mic/loopback.
4. Непустой текст → канальный фильтр коротких/шумовых фраз → колбэк пайплайна.

## Защита от самоуслышивания

Пока Нимфея говорит (пайплайн вызывает `pause(True)`), запись глушится —
её собственный голос не вернётся ей как вопрос.

## Настройки (core/config.py)

- `NIMA_STT_MODEL` — `small` (дефолт, быстро) / `medium` / `large-v3` (макс.
  качество, медленно на CPU). Первая загрузка качает модель с HuggingFace.
- `NIMA_STT_SILENCE_CUT` — тишина-конец фразы (0.5 с);
- `NIMA_STT_RMS_THRESHOLD` — порог чувствительности микрофона (0.004); если
  Нимфея глуховата — уменьши, если реагирует на шум — увеличь;
- `NIMA_STT_MIC_PROMPT` / `NIMA_STT_LOOP_PROMPT` — отдельные подсказки каналов;
- `NIMA_STT_WHISPER_VAD=1` — вернуть внутренний VAD Whisper;
- `NIMA_STT_LOOP_MIN_WORDS` / `NIMA_STT_LOOP_MIN_TEXT_CHARS` — фильтр коротких
  loopback-срабатываний (значение `0` отключает соответствующий фильтр).

## Изоляция

Модуль не знает про пайплайн/LLM: только колбэк. Пауза — команда снаружи.
